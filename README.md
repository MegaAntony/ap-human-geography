# AP Human Geography Study Hub

Collection of interactive study materials, FRQ guides, and Multiple Choice Question (MCQ) mastery banks for AP Human Geography based on the AMSCO Advanced Placement Human Geography (2nd Edition) curriculum.

## 📁 Repository Structure

### 🎯 `exam-001-mcq/` (Multiple Choice Practice Portal)
Interactive practice exam modules with real-time scoring, randomized option lengths (no guessing heuristics), subtopic filtering, and detailed explanations for each choice:
- **`exam-001-mcq/index.html`**: Main MCQ Practice Dashboard
- **`exam-001-mcq/AMSCO_1.1_MCQ_Practice.html`**: Topic 1.1 — Introduction to Maps (40 Qs)
- **`exam-001-mcq/AMSCO_1.2_MCQ_Practice.html`**: Topic 1.2 — Geographic Data (40 Qs)
- **`exam-001-mcq/AMSCO_1.3_MCQ_Practice.html`**: Topic 1.3 — The Power of Geographic Data (40 Qs)
- **`exam-001-mcq/AMSCO_7.2_MCQ_Practice.html`**: Topic 7.2 — Economic Sectors & Patterns (40 Qs)
- **`exam-001-mcq/AMSCO_7.3_MCQ_Practice.html`**: Topic 7.3 — Theories & Models of Development (40 Qs)
- **`exam-001-mcq/AMSCO_7.5_MCQ_Practice.html`**: Topic 7.5 — Deindustrialization & Restructuring (40 Qs)

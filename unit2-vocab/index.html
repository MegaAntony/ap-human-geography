How to use this page

This page helps you learn the 64 Unit 2 (Population and Migration) vocabulary words, using AMSCO wording, so you can prepare for the Unit 2 Vocabulary Summative on Monday, October 26 in Mrs. Knight's AP Human Geography class. The same words also help on the MCQ summative on October 28 and 29.

Each day, in this order

  1. Start with yesterday's misses. Open "Missed terms" for 5 minutes.
  2. Find today's row in "This week". It tells you the topics, AMSCO pages, and videos.
  3. Read the AMSCO pages and watch the video for that topic.
  4. Learn each card: read the hint, then "Show AMSCO wording" (your test uses this wording), then the example and watch-out.
  5. Say it out loud, then cover the card and write it from memory.
  6. Mark it honestly: "I know this" or "Still learning".
  7. Test yourself with flashcards, then the quiz. A word counts as learned after 2 right answers in a row.

      Source notes

      • AMSCO printed page = PDF page + 52 (pages 55-122 used).
      • AP Daily video tags. Files are named AP_Daily_<topic>_Video_<n>_*.mp4. Tags used: 2.1 V1, 2.1 V2, 2.2 V1, 2.2 V2, 2.3 V1, 2.4 V1, 2.4 V2, 2.5 V1, 2.5 V2, 2.6 V1, 2.7 V1, 2.8 V2, 2.9 V1, 2.10 V1, 2.10 V2, 2.11 V1, 2.11 V2, 2.12 V1.
      • Terms in no video: infrastructure, baby bust, baby echo, demographic momentum, migration transition model, transhumance, xenophobia, ethnic enclaves.
      • Terms with no formal AMSCO definition (usage only): baby bust, baby echo, crude death rate, chain migration, rural-to-urban migration.

      Where sources differ (each one is a watch-out on its card)

      • Egypt densities: AMSCO 226 (arithmetic) and 8,078 (physiological); video 98 and 6,995; teacher slides 257 and 9,182.
      • Dependency ratio: AMSCO p. 101 sentence says potential workforce divided by dependents; its table divides dependents by workers. Dependents: AMSCO over 64, video over 65.
      • DTM stage names: AMSCO uses high stationary, early expanding, late expanding, low stationary, declining. AP Daily uses low, high, moderate, low, negative growth.
      • China policy: AMSCO says modified in 2016; the 2.7 video says 2015.
      • RNI (AMSCO and organizer) and NIR (AP Daily) are the same measure.
      • Transnational migration: AMSCO means simply moving between countries.
      • Baby boom: AMSCO says 1946 to 1965; the glossary says 1946 to 1964.

### Question 1 (1.3-Q01)
- **CED Skill:** `Skill 1.A` — *Describe geographic concepts, processes, models, and theories.*
- **AMSCO Reference:** Geographic Information Systems (GIS) (*AMSCO 2nd Ed, Topic 1.3, under 'Geographic Information Systems (GIS)'*)

> **Prompt:** Which of the following descriptions accurately characterizes a Geographic Information System (GIS)?

- **(A)** A computer system that captures, stores, analyzes, and layers spatial data.
- **(B)** A network of orbital satellites transmitting synchronized radio timing signals.
- **(C)** A handheld receiver calculating terrestrial elevation using atomic time clocks.
- **(D)** A specialized photographic camera capturing multispectral radiant light waves.

<details><summary><b>Reveal Answer & Detailed Rationale</b></summary>

- **Correct Answer:** **(A)**
- **Summary Rationale:** A Geographic Information System (GIS) is a computer software and hardware framework designed to capture, store, manipulate, analyze, manage, and visualize multiple thematic layers of georeferenced spatial data.
- **Why other options are incorrect:**
  - **(B):** A network of orbital satellites broadcasting radio timing signals describes the Global Positioning System (GPS), not a GIS.
  - **(C):** A handheld receiver calculating altitude and position via atomic clocks is a GPS receiver unit.
  - **(D):** A multispectral camera mounted on aircraft or satellites represents remote sensing hardware.
</details>

  - **(B):** Qualitative oral narratives represent humanistic fieldwork, completely unrelated to satellite geodesy.

### Question 4 (1.3-Q04)
- **CED Skill:** `Skill 1.A` — *Describe geographic concepts, processes, models, and theories.*
- **AMSCO Reference:** GIS Data Structures: Vector vs. Raster Data (*AMSCO 2nd Ed, Topic 1.3, under 'GIS Data Formats: Vector and Raster'*)

> **Prompt:** In a Geographic Information System (GIS), how does vector spatial data fundamentally differ from raster spatial data?

- **(A)** Vector data represents continuous elevation grids while raster data maps point coordinates.
- **(B)** Vector data stores qualitative interviews while raster data compiles monetary trade figures.
- **(C)** Vector data records satellite photos while raster data demarcates legal property boundaries.
- **(D)** Vector data uses points, lines, and polygons while raster data uses a grid of square cells.

<details><summary><b>Reveal Answer & Detailed Rationale</b></summary>

- **Correct Answer:** **(D)**
- **Summary Rationale:** In GIS, vector models represent discrete geographic features using coordinate points, lines (roads, rivers), and polygons (parcels, lakes), whereas raster models represent continuous surfaces using regular grid cells or pixels (satellite imagery, elevation rasters).
- **Why other options are incorrect:**
  - **(A):** This reverses the two: raster grids display continuous elevation, while vector points map exact coordinates.
  - **(B):** Vector and raster are both spatial data formats; neither is defined as raw interview audio or monetary figures.
  - **(C):** Satellite photos are stored as raster grids, while legal property parcels are stored as vector polygons.
</details>

- **(B)** The 5-centimeter drone image cannot be projected onto two-dimensional flat computer mapping interfaces.
- **(C)** The 30-meter satellite data is legally banned for civilian academic environmental research projects.

<details><summary><b>Reveal Answer & Detailed Rationale</b></summary>

- **Correct Answer:** **(D)**
- **Summary Rationale:** Spatial resolution defines the size of the smallest ground feature represented by a single pixel: high-resolution drone imagery (5 cm) reveals fine physical details over localized footprints, whereas moderate-resolution satellite imagery (30 m) covers vast regional landscapes in a single pass.
- **Why other options are incorrect:**
  - **(A):** This reverses the resolutions: 5-centimeter drone imagery identifies cars, while 30-meter pixels average large terrain patches.
  - **(B):** Drone imagery is routinely georeferenced and projected onto 2D computer screens and GIS maps.
  - **(C):** 30-meter satellite imagery (such as USGS Landsat) is free, open, and standard for academic research globally.
</details>
